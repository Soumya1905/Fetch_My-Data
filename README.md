# Fetch My Data

A full-stack file transfer app that lets an Android phone browse, upload, and download files stored on a laptop.

The phone and laptop are paired by scanning a **QR code**, and the connection works through **Tailscale**, allowing the devices to communicate even when they are on different networks.

## Components

### Android App — This Repository

- **Kotlin**
- **Jetpack Compose**
- **Navigation Compose**
- **MVVM** with ViewModel and StateFlow
- **Ktor Client** with OkHttp engine
- **Jetpack DataStore** for storing pairing information
- **Google ML Kit Code Scanner** for QR-based pairing

### Backend — `LaptopSyncProject`

The backend runs separately on the laptop.

- **Kotlin**
- **Ktor Server**
- **Netty**
- **kotlinx.serialization**
- **Ktor Multipart** for file uploads

## How It Works

### 1. Connect through Tailscale

Tailscale is installed and signed in on both the laptop and Android phone.

The laptop receives a private Tailscale IP address that can be reached by the phone even when the devices are connected to different networks.

The file-transfer traffic travels through Tailscale's encrypted WireGuard tunnel.

### 2. Start the laptop server

The laptop runs the Ktor backend.

When the server starts, it generates a QR code containing:

- Server host
- Server port
- Pairing token

The QR code is displayed directly in the server's console.

### 3. Pair the phone

From the Android app's Home screen, the user selects **Pair with Laptop** and scans the QR code displayed by the laptop server.

The pairing information is stored locally using **Jetpack DataStore**.

### 4. Access files

After pairing, the Android app communicates with the laptop backend using the stored server information and bearer token.

The user can then:

- Browse files and folders
- Upload files
- Download files

Every request that accesses the laptop's filesystem is authenticated using the pairing token.

## Features

### 🔗 QR Code Pairing

Pair the Android device with the laptop by scanning a QR code generated by the backend.

### 🌐 Remote Connectivity

The application uses **Tailscale** so the phone and laptop can communicate across different networks instead of requiring both devices to be connected to the same Wi-Fi network.

### 📁 File Browsing

- Browse files and folders on the laptop
- Navigate between folders
- View the contents of the configured shared directory

### ⬆️ File Upload

Upload files from the Android phone directly into the folder currently being viewed on the laptop.

### ⬇️ File Download

Download files from the laptop to the Android phone.

Downloads include:

- Per-file progress
- Disabled download button while a file is being downloaded

### 📂 Configurable Shared Folder

The backend supports a configurable root directory.

By default, it uses the laptop user's home directory, for example:

```text
C:/Users/<you>
```

A different directory can be configured in `application.yaml`.

### 🔐 Authentication

Every filesystem-related request requires a valid bearer token generated during pairing.

### 🛡️ Path Traversal Protection

The backend validates requested paths to prevent access outside the configured shared root directory.

## Setup

### 1. Backend — `LaptopSyncProject`

#### Install Tailscale

Install Tailscale on the laptop and sign in.

The Android phone must also be signed into the same Tailscale account or otherwise have access to the laptop through the configured Tailscale network.

#### Run the backend

Open `LaptopSyncProject` in IntelliJ IDEA and run the Ktor application.

By default, the server exposes the laptop user's home directory.

To use a different folder, edit:

```text
src/main/resources/application.yaml
```

For example:

```yaml
app:
   rootFolder: "G:/SomeOtherFolder"
```

When the server starts, it generates and prints a QR code in the run console.

Keep the server running while using the Android application.

### 2. Android App — This Repository

#### Install Tailscale

Install Tailscale on the Android phone and sign into the same account/network used by the laptop.

#### Build and install

Open the project in Android Studio and build/install the application on the Android device.

#### Pair the devices

1. Open the app.
2. Go to the Home screen.
3. Tap **Pair with Laptop**.
4. Scan the QR code displayed in the backend's console.
5. Wait for the connection status to show **🟢 Connected**.

The application is now ready to access the laptop's files.

## Security

The application uses several layers of protection for file access.

### Tailscale

Network traffic between the devices is protected by Tailscale's WireGuard-based encrypted tunnel.

### Bearer Token Authentication

A pairing token is generated by the backend and included in the QR code.

The Android application sends the token with subsequent requests, and the backend validates it before processing filesystem operations.

### Path Traversal Protection

The backend restricts filesystem access to the configured root directory, preventing requests from navigating outside the shared folder.

## Known Limitations

- There is currently no additional application-layer encryption beyond the encryption provided by Tailscale.
- Duplicate filename handling during downloads relies on Android's Storage Access Framework. Android typically creates a new filename with a suffix instead of overwriting the existing file, but this behavior is not independently enforced by the application.
- Automated tests have not been implemented yet.
